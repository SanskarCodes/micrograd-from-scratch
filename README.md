# Micrograd From Scratch

A minimal autograd engine built in Python to understand automatic differentiation and neural network fundamentals.

## Concepts Covered

- Computational graphs
- Scalar-valued operations
- Derivatives and the chain rule
- Backpropagation
- Building a simple neural network

## Tech Stack

- Python
- NumPy
- Google Colab

## Learning Outcomes

- Understanding how gradients flow through computational graphs
- Implementing backpropagation
- Understanding the fundamentals behind neural network training
